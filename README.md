# La Gaceta de la Soberanía C2C

Edición interactiva autocontenida de La Gaceta. La portada incorpora tres fotografías editoriales en base64 dentro del propio HTML; los diagramas y herramientas interactivas forman parte del documento.

## Publicación con GitHub Pages

El archivo de entrada es `index.html` en la raíz de `main`.

Para activar el sitio: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Una vez que GitHub Pages complete el despliegue, la dirección esperada es:

https://grenerchile.github.io/funzine/
